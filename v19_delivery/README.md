# 전란고아 v19 GUI GitHub 전달본

ChatGPT/Gmail 첨부 차단을 피하기 위한 GitHub 복구 패키지입니다.

1. GitHub에서 `v19-gui` 브랜치를 선택합니다.
2. **Code → Download ZIP**으로 브랜치를 다운로드합니다.
3. 압축을 풉니다.
4. `RESTORE_AND_RUN.bat`을 더블클릭합니다.
5. `payload/part_*.txt`를 결합하여 원본 프로젝트 ZIP을 복구하고 SHA-256을 검증한 뒤 게임을 실행합니다.

원본 압축 SHA-256: `b38098677bb22d509393600f3dbc72e29c60ff56658fefb24c800a93d4472759`
조각 수: 25

최초 GUI 실행 시 PySide6 설치를 위해 인터넷 연결과 Python이 필요합니다.
