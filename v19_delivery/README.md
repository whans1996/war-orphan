# 전란고아 v19 GUI GitHub 전달본

ChatGPT/Gmail 첨부 차단 문제를 피하기 위한 전달 페이지입니다.

## 가장 쉬운 다운로드
Google Drive에 실제 ZIP을 업로드했습니다.

- 파일: `txtrpg_v19_recovered_gui.zip`
- Drive: https://drive.google.com/file/d/1NJ2lYZw-3kQBx7sMDf9EhPmJwXbKGAiE/view?usp=drivesdk
- SHA-256: `b38098677bb22d509393600f3dbc72e29c60ff56658fefb24c800a93d4472759`

다운로드 후 압축을 풀고 `txtrpg_project/START_GAME.bat`을 실행하세요.
최초 실행 시 `.venv`와 PySide6 설치가 자동 진행됩니다.

## GitHub 브랜치
현재 전달용 브랜치는 `v19-gui`입니다.
기존 `main` 브랜치는 변경하지 않았습니다.

## 참고
GitHub 커넥터는 로컬 ZIP 바이너리를 직접 Release asset으로 업로드하는 기능이 없어, 실제 실행 ZIP은 Drive에 두고 GitHub에는 전달 정보와 복원 스크립트를 유지합니다.
